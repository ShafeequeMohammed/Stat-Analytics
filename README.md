# Stat-Analytics
A comprehensive data project that combines classical statistical inference with modern analytics


##  Project Overview
This repository is a comprehensive data project that combines classical statistical inference and hypothesis testing with modern analytical tools, interactive dashboards, and scalable data workflows. 

The goal is to apply rigorous mathematical foundations to real-world datasets to uncover deep, actionable insights.

##  Tech Stack & Tools
* **Languages:** Python (Pandas, NumPy, SciPy, Statsmodels) / R
* **Visualization:** Matplotlib, Seaborn, Tableau / Power BI
* **Modern Analytics:** SQL, Scikit-Learn (for predictive modeling)
* **Environment:** Jupyter Notebooks / VS Code

##  Statistical Methods Implemented
* **Descriptive Statistics:** Data distribution, central tendency, and variance analysis.
* **Inferential Statistics:** Hypothesis testing (A/B testing, t-tests, ANOVA, Chi-Square).
* **Predictive Analytics:** Linear & Logistic Regression, time-series forecasting.
* **Modern Data Workflows:** Exploratory Data Analysis (EDA) and automated data cleaning pipelines.
